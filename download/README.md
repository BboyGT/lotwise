This directory contains the images used by the project documentation and the Lotwise interface.

The root README uses the numbered screenshots below to show the current interface:

1. `01-synthetic-overview.png` — main calculator and synthetic market view

3. `03-rr-bar.png` — risk-to-reward display and minimum-lot warning
4. `04-crypto-btc.png` — crypto market view
5. `05-crypto-calc.png` — crypto position calculation
6. `06-forex-eurusd.png` — forex market view
7. `07-alarm-panel.png` and `08-alarm-settings.png` — alerts and alarm settings
8. `09-equity-curve.png` — trade journal statistics
9. `10-legal-modal.png` — legal information
10. `11-mobile-view.png` and `12-mobile-calc.png` — mobile layouts
11. `13-logo.png` and `logo.svg` — project logo assets

Only the numbered README screenshots and logo assets are included in the public repository. Local design and development captures are ignored by Git.
